# Pixel Swarm: term sheet

Built during the text review. Use it as a starting style guide.

## Terms

| Concept | Use | Avoid | Notes |
|---|---|---|---|
| The creatures the player sends | bugs | bees (unless the Bee is meant) | 6 bug types; the collection tab is "Bugs" (TXT-001) |
| The row of blocks at the bottom | the line | line (without "the"), queue | TXT-004 |
| Losing state | Out of Slots (named state, highlighted) | out of slots (in running text) | TXT-005 |
| Premium currency | gems | diamonds, crystals | consistent today |
| Soft currency | coins | gold | consistent today |
| Difficulty | Easy, Medium, Hard | easy/normal/hard | consistent today |
| Puzzle elements | New Feature cards | puzzles, mechanics (in UI) | How to Play says "Puzzles:" as the card label |

## Capitalisation

| Element | Style | Examples |
|---|---|---|
| Popup and screen titles | Title Case | How to Play, Level Complete!, Special Offer |
| Buttons | Title Case | Add Slot, Try Again, Give Up, Exit to Menu |
| Feature card titles | Title Case (plural vs singular open, QRY-001) | Mystery Blocks, Big Pixel |
| Toasts and descriptions | Sentence case | Not enough gems (need 30) |
| Badges | ALL CAPS | IN USE, PREVIEW, YOU ARE HERE |

## Punctuation

- Ellipsis: use the single character "…" (TXT-006).
- Exclamation marks: titles of reward popups and tutorial lines use "!"; descriptions end with ".".
- Dashes: em dash with spaces ("Privacy Policy — coming soon").
- Spelling: US English (color, armor, honorable).
